# fender8891's Target Dummy

A standalone NeoForge 1.21.1 combat-testing mod extracted from ObeseCat.

## Features

- Placeable, reusable Target Dummy
- Armor and hand equipment slots
- Floating health, armor, and last-hit damage card
- Toggleable information card
- Sneak-right-click to pack up the dummy and return its equipment

## Build

Run `gradlew.bat build`. The built JAR is written to `build/libs`.
